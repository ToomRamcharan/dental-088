# Partha Dental - Khammam

**Dental Clinic Website** - Generated from UI UX Pro Max Design System

## Design
- **Design Family:** Editorial
- **Color Palette:** Charcoal Clinic
- **Location:** Khammam, Telangana

## Tech Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Sections
Home, About, Services, Doctors, Technology, Testimonials, Gallery, FAQ, Contact, Google Map, Footer

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
